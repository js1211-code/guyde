## 1. 개요

**문제:** 자기관리에 관심 생긴 20대 남성은 (1) 뭐부터 할지 모르고 (2) "이거 이상하지 않나"를 물어볼 곳이 없다. 유튜브는 순서가 없고, 인스타는 실명·공개라 못 물어보고, 인플루언서는 동경만 유발한다.

**솔루션:** 익명으로 올리면 **대중이 투표·댓글로 "무난함"을 검증**해주는 커뮤니티. 질문자는 익명(심리 안전), 답변자는 실명+온도(신뢰). 잘 답하면 온도가 오르고, 온도 상위 10%는 유료 컨설팅으로 수익화(고수).

**포지션:** 안티-동경. "멋져져"가 아니라 **"안 망해."**

**해커톤 데모 목표:** 3분 발표 안에 심사위원에게 두 가지를 증명한다 — ① 커뮤니티가 살아있다(실시간 투표) ② 수익 모델이 구조적으로 붙어있다(하트·컨설팅 에스크로).

## 4. 핵심 유저 플로우

1. **질문자 루프:** 로그인 → 하트 확인 → 익명 글 작성(사진+선택지, 하트 1 차감) → 투표·댓글 수신(실시간) → 베스트답변 채택 → status: answered
2. **답변자 루프:** 피드 탐색 → 투표/댓글 → 추천·베스트 채택받음 → 온도 상승 → (상위 10%) 고수 자격 → 컨설팅 판매
3. **신규 유입 루프(바이럴):** 유형테스트(비로그인 가능) → 결과 "상위 n%" → 공유 → 가입 → 질문자/답변자로 전환

## 5. 기능 요구사항

우선순위: **P0 = 데모 필수(완전 동작)** / P1 = 데모 포함(간소화 동작) / P2 = 흐름 시연(목업 허용)

### F0. 온보딩 / 인증 — P0
- 구글 소셜 로그인(카카오는 여유 시, §10). 최초 로그인 시 닉네임 설정(중복 불가) + **가입 보너스 하트 5개 자동 지급**.
- 열람은 비로그인 허용, 행동(글·투표·댓글)은 로그인 요구.
- ✅ AC: 신규 가입 직후 잔액 5 · `heart_transactions`에 `signup_bonus` 1행 · 닉네임 중복 시 에러 안내.

### F1. 익명 글 작성 — P0
- 입력: 본문(필수) · 사진 0~2장 · 선택지 2~4개(텍스트, 사진 선택) · 카테고리(헤어/패션/스킨케어/전반) · D-day(선택: 소개팅/면접 날짜).
- 하트 1 차감(서버 트랜잭션). **잔액 0이면 작성 차단 + 충전(광고) 유도 모달.**
- 작성자는 모든 화면에서 "익명" 표시.
- ✅ AC: 잔액 0 작성 시도 → 차단 · 작성 성공 시 잔액 -1 & 원장 1행 · **클라이언트 API 응답 어디에도 author_id 없음**(posts_feed 검증됨) · 글 수정/삭제는 스코프 아웃.

### F2. 피드 — P0
- 최신순 리스트, 카테고리 탭 필터. 카드: 익명 뱃지 · 본문 1~2줄 · 썸네일 · 투표 진행률 미리보기 · 댓글 수 · 상대시간 · (D-day 글) "소개팅 D-3" 뱃지.
- 페이지네이션은 "더보기" 버튼으로 충분(데모).
- ✅ AC: 비로그인도 피드 열람 가능 · 카테고리 필터 정상 · 빈 카테고리는 빈 상태 UI.

### F3. 선택지 투표 — P0
- 1인 1투표(글 단위), 재투표 시 마지막 선택으로 변경(upsert). 투표 후 퍼센트+막대 공개.
- **Realtime: 다른 사용자 투표가 2초 내 화면 반영.** (데모 킬러 장면)
- ✅ AC: 같은 유저 중복 투표 불가(DB unique 검증됨) · 다른 글 선택지로 투표 불가(복합 FK 검증됨) · 두 기기 동시 시연 시 실시간 반영.

### F4. 댓글 + 베스트답변 — P0
- 댓글: **실명 + 온도 뱃지** 표시, 대댓글 1단, 추천(1인 1추천, 취소 가능 — upvotes 트리거 자동).
- 베스트답변: **질문자만** 채택 가능, 글당 1개. 채택 시 글 상단 하이라이트 + `posts.status='answered'` + 답변자 온도 +0.5.
- ✅ AC: 채택 시 reputation_events('best_answer') 1행 & 온도 갱신 일치 · 질문자 아닌 유저에겐 채택 버튼 미노출 · 추천 수 = comment_votes 행 수와 항상 일치.

### F5. 온도 / 등급 — P0
- 시작 36.5. 이벤트: 댓글 추천 +0.1 · 베스트 채택 +0.5 · 컨설팅 후기 4~5점 +0.3 / 1~2점 -0.3. *(수치는 §7 가설)*
- 프로필: 온도 게이지(36.5 기준, 높을수록 주황) + 등급 뱃지 + "고수까지 상위 n%" 진행률.
- 등급: 베이스(기본) → 스탠다드(38.0↑) → 마스터(39.0↑). **고수 자격 = 온도 상위 10%**(percent_rank).
- 비활동 감쇠는 **자동화하지 않음**(설계만, Q&A 대비).
- ✅ AC: 모든 온도 변화에 reputation_events 근거 1행 · 원장 재계산값 = 캐시값.

### F6. 하트 경제 — P1
- 잔액 UI(헤더 상시 노출) · 광고 시청 **목 버튼**("광고 보기" → 3초 대기 연출 → +2) · 구매팩 UI는 화면만(결제 미연결).
- 모든 증감은 spend_hearts/earn_hearts 함수 경유(서버).
- ✅ AC: 광고 버튼 → 잔액 +2 & ad_reward 원장 1행 · 마이페이지에서 하트 내역 리스트 확인 가능.

### F7. 바이럴 유형테스트 — P1
- 8문항 → 4유형(예: 무난 표준형 / 각성 직전형 / 과투자형 / 무개념 노베이스형 — 카피는 UX 라이팅에서 확정) → 결과 저장(quiz_results) → **"나는 상위 n%"**(동일 유형 비율 집계) → 링크 복사 공유 → 비로그인 응시 허용, 결과 화면에서 가입 유도 CTA.
- ✅ AC: 비로그인 응시·저장 가능 · 결과 페이지 새로고침에도 유지(URL로 접근 가능) · 상위 % 실데이터 집계.

### F8. 고수 컨설팅 + 결제 — P2
- 고수 리스트(온도 상위 10% 자동 뱃지) → 상품 상세(채팅 ₩9,900 / 화상 ₩29,000) → 예약 → **토스페이먼츠 샌드박스 결제** → 에스크로 상태 UI(paid_escrow → in_session → completed 버튼 전이) → 후기(별점) → 온도 반영.
- 실제 송금·정산 없음. 채팅/화상 자체는 구현 안 함(상태 전이만).
- ✅ AC: 테스트 결제 성공 → bookings.status='paid_escrow' · 상태 전이 버튼으로 completed까지 진행 · 후기 등록 → 온도 반영.

### F9. 운영 최소 — P2
- 글·댓글 신고 버튼(reports 적재만, 관리 화면 없음).

### 비기능 요구사항 (NFR)
- **모바일 퍼스트**: 390px 기준 설계, 데스크톱은 중앙 정렬 컬럼.
- **익명성(제품 약속)**: 클라이언트에서 어떤 API를 호출해도 질문 글 작성자 식별 불가.
- **보안**: RLS 상시 on · 돈/평판 변동은 서버 전용 · 테스트 키만 사용(실결제 금지).
- **성능**: 피드 첫 로드 3초 이내(시연 네트워크 기준), 투표 반영 2초 이내.

## 9. 릴리즈 계획 & 데모 시나리오

**남은 일정(요약):** Day 2 글작성+피드+투표(Realtime) → Day 3 댓글+베스트+온도 → Day 4 하트 → Day 5 유형테스트+컨설팅 결제 → Day 6 폴리시+시드+배포 → Day 7 리허설+백업 녹화. *(상세는 기술 스택 문서 §5)*

**데모 시나리오 (3분):**
1. (30초) 문제·포지셔닝 — "멋져져가 아니라 안 망해"
2. (60초) **핵심 루프 라이브** — 익명 글 작성 → 관객 폰 QR 투표 → 발표 화면 실시간 반영
3. (40초) 베스트답변 채택 → 답변자 온도 상승 → 등급/고수 게이트 설명
4. (30초) 하트 차감·광고 충전(수익 모델 1)
5. (40초) 고수 컨설팅 → 토스 테스트 결제 → 에스크로 상태(수익 모델 2) → 마무리: "3년 SOM 35억, 커머스 얹으면 100억 경로"

**리스크 대비:** 시연 실패 대비 백업 녹화 영상 필수(Day 7).
